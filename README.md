# SketchQuint

SketchQuint is a cloud-based machine-learning platform providing automated-annotation and real-time-processing capabilities for the Core Suite.

SketchQuint is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchQuint.git`
2. `cd SketchQuint`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SketchQuint, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
